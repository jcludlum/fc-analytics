# Claude Code Project Rules

**Git repository:** `fc-analytics`

## Commit Guidelines

- **Single-Objective**: Enforce small, atomic commits covering one specific change.
- **Message Format**: Start with a common prefix (`feat:`, `fix:`, `docs:`, `refactor:`, `perf:`, `test:`, `chore:`).
- **Length**: Keep summary lines concise and succinct.

## Recipe Markdown files

When the user asks you to create recipe Markdown files, follow the instructions 
in `data/RECIPE_INSTRUCTIONS.md`.
