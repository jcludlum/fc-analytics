# Fine Cooking Analytics

A Streamlit app for browsing and searching recipes digitized from *Fine Cooking* magazine (1994–2019).

**GitHub repository:** https://github.com/jcludlum/fc-analytics

**Streamlit app:** https://fc-analytics.streamlit.app

To run locally:

```bash
uv run streamlit run src/fc_analytics/app/Home.py
```
